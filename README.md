# MOOD_BUDDY
Mood Buddy: A Digital Sanctuary

Mood Buddy is a web-based wellness companion designed to provide a judgment-free, private space for emotional venting and mood tracking. Built as a Final Year Project, 
this application focuses on the intersection of Human-Computer Interaction (HCI) and Mental Wellness, prioritizing user privacy and aesthetic calm.


Project Overview

In a digital landscape dominated by intrusive data collection and clinical AI, Mood Buddy offers a "Sanctuary" approach. 
It utilizes a Static Emotional Logic System to validate user feelings without the need for external API dependencies. 
This ensures 100% uptime, zero data leakage to third-party AI providers, and a consistent, empathetic user experience.


Key Features

Multi-Stage User Authentication: Secure Sign-Up and Login flow using hashed credentials.

Aesthetic UI/UX: A "Digital Lavender" and "Deep Violet" color palette designed to lower heart rates and reduce user anxiety.

Contextual Greeting System: Personalized, warm greetings upon login to build immediate user trust.

Static Sentiment Response Engine: Keyword-based emotional validation that avoids the "interrogation" feel of traditional chatbots.

Mood Analysis Dashboard: A session-based report that tracks emotional patterns and provides a summary of the user's primary "vibe."


Tech Stack

Frontend/Backend: Streamlit (Python Framework)

Database: SQLite3 (Local, lightweight relational database)

Security: Passlib (SHA-256 password hashing)

Logic: Custom Sentiment Analysis Engine (Static Keyword Mapping)

Styling: CSS3 Injection (Custom UI modification)

Design Philosophy

"We don't give advice. We don't interrogate. We just listen."

Mood Buddy is built on the principle of Validation over Solution. For many users, the barrier to seeking mental wellness tools is the fear of being judged or given generic, robotic advice.
Mood Buddy removes this barrier by focusing purely on active listening and visual comfort.

Future Scope

Transition to a PostgreSQL database for persistent cloud storage.
Integration of local LLMs for deeper offline conversational capabilities.
Implementation of advanced data visualization for long-term mood trends.
